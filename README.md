# netflix-data-analysis
Python data analysis project exploring Netflix content trends, countries, and TV show vs movie distribution.

## Project Overview
This project analyzes Netflix content data using Python, Pandas, and Matplotlib. The analysis explores content distribution, countries, release years, and Movies vs TV Shows.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Dataset exploration
- Missing values analysis
- Movies vs TV Shows comparison
- Top countries producing Netflix content
- Release year trend analysis
- Data visualization

## Skills Demonstrated
- Data analysis
- Data visualization
- Exploratory data analysis (EDA)
- Python programming
- Working with Pandas DataFrames
